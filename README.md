# Tip Check

**A small, responsive tip calculator built with plain HTML, CSS, and JavaScript.**

Tip Check helps calculate a tip and split a restaurant bill with a simple interface, quick percentage presets, and light/dark themes.

## Features

- Bill amount input
- Editable tip percentage with 10%, 15%, and 20% presets
- Tip and total calculation
- Bill-splitting support, where enabled in the current UI
- Responsive layout
- Light and dark theme toggle
- Accessible labels and keyboard-friendly controls

## Run locally

This is a static single-page app with no build step.

```bash
git clone https://github.com/kishorekrrish3/Build-a-Mini-App-with-Cursor.git
cd Build-a-Mini-App-with-Cursor
```

Open `index.html` in a modern browser, or serve the directory with a local static web server.

## Tech stack

- HTML
- CSS custom properties and responsive styling
- Vanilla JavaScript
- Google Fonts (optional network request for typography)

## Notes

Calculations run in the browser and are intended for convenience. Check the displayed amounts before settling a real bill. If you use the project as a learning exercise, try adding currency selection, rounding rules, automated tests, or a shareable bill summary.
